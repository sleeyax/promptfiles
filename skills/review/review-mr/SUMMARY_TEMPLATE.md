# Summary draft-note template

Fill this shape once per review and post as a non-positional draft note.

```
## Code review summary

**Reviewers:** `<agent>` (`<model>`) — N findings · `<agent>` (`<model>`) — M findings
**Files reviewed:** N — `path/a`, `path/b`, …
**Findings:** X blocker · Y concern · Z suggestion · W nit

<2–4 plain sentences in first person: what was reviewed, recommendations, effort estimate. State here if review was diff-only (no local checkout).>

> [Generated by AI](https://github.com/sleeyax/skills/blob/main/skills/review/review-mr/SKILL.md) (agent: `<agent>`, model: `<model>`).
```

## Rules

- **Reviewers**: one `agent (model)` pair per reviewer with that reviewer's raw finding count, before deduplication. Omit the whole line when a single reviewer ran — the footer already names it.
- **Files reviewed**: count + comma-separated list of paths in backticks. For long lists, truncate to 5 with `…and N more`.
- **Findings**: tally each severity tier; omit a tier if its count is `0` (e.g. `2 concern · 1 nit`). If zero findings overall, write `**Findings:** none`. The tally counts the deduplicated set, so it won't equal the sum of the per-reviewer counts on the **Reviewers** line.
- **Body**: first person (`I`), no bullets, no headers, no score. Effort estimate in plain English (`a small fix`, `moderate rework`, `substantial redesign`). Mention diff-only mode here when applicable.
  - After a multi-reviewer run, cover both reviewers here: what each one found, how many findings they agreed on, and where they diverged. Agreement is a confidence signal — say so.
- **Footer**: substitute `<agent>` with the agent name (e.g. `Claude Code`, `Codex CLI`) and `<model>` with the model identifier in use (e.g. `claude-opus-4-7`, `gpt-5-codex`). Both stay inside the backticks. Don't leave the placeholders literal.
  - When the **Reviewers** line is present it carries the attribution, so the footer drops the parenthetical: `> [Generated by AI](…).`
